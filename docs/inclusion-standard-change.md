# 纳排标准收紧：金集从 6 篇变成 2 篇（2026-11-19）

> 课题组把标准定死了：**只算 COF 骨架**。姊妹体系（CMP / PHI / 碳氮 / CdS）不纳入。
>
> 这一条改完之后，**我们的一条主结论不再成立**。记在这里，不藏。

## 一、标准的两档

| | 内容 |
|---|---|
| **严格（原始）** | 产 H₂O₂ + 耦合 + 涉及 COF。耦合＝产 H₂O₂ 的同时把低价值有机物变成高价值有机物 |
| **现行** | 产 H₂O₂ + 涉及 COF。文献太少，暂时不要求耦合 |

2026-11-19 追加定死：现行标准里的「涉及 COF」**只算骨架是 COF 的**，不含姊妹体系。

## 二、金集的重新划线

| 论文 | 材料 | 原来 | 现在 |
|---|---|---|---|
| adfm.202510257 | COF | 阳性 | **阳性** |
| jacs.6c00731 | COF | 阳性 | **阳性** |
| adfm.202316773 | CMP | 阳性 | 不纳入 |
| apcatb.2024.124896 | KNPHI | 阳性 | 不纳入 |
| adfm.202510323 | Bi₂O₂S/CuInS₂ | 阳性 | 不纳入 |
| aenm.71443 | CdS | 阳性 | 不纳入 |

注意：这四篇标的是 **1（不纳入）**，不是 **0（不算）**。
它们不是「判断错了」，是「不属于这次综述的范围」。这两件事混在一起，账就永远算不清。

## 三、后果：一条主结论倒了

重跑检索侧：

```
A. 只搜 COF        815 篇   2/2
B. 六族并集      2,838 篇   2/2
C. 加三条修正    2,850 篇   2/2
```

**只搜一种材料体系，就已经 2/2。**

原来那个「单轴 2/7 → 六族 7/7」的故事讲的是：换检索维度能把覆盖从 2 提到 7。
现在看清楚了——**多出来的那 4 篇从来不是 COF**，它们本来就不该在分母里。

也就是说：**不是 COF 单轴检索漏了，是我们把不该数的算进了分母。**

## 四、这条错为什么难发现

它不难在技术上，难在**它一直看起来是对的**：
- 数字确实在涨（2 → 6），没人会怀疑一个变好的指标；
- 每一篇被「救回来」的论文都是真论文、真相关；
- 只有把「标准」写下来、和「分母」对一遍，才会发现分母从一开始就是错的。

这跟我们之前踩的九个坑是同一类：**安静地给出一个看起来正常的错答案。**

## 五、现在真正的风险变了

以前怕的是「姊妹体系漏搜」。现在这个风险不存在了，换成两个：

1. **COF 论文不写「COF」这个词。**
   有的文章只用材料代号（TpPa-1、BT-COF、CTF-SO），摘要里一次都不出现
   `covalent organic framework`。这类才会被单轴真正漏掉——而且**现在的 2 篇阳性
   测不出来**，因为这两篇都写了。

2. **2 篇阳性撑不起任何结论。**
   2/2 不能被读成「检索没问题」，只能读成「目前没发现有问题」。
   这和「没有误报」≠「没验过」是同一个道理。
