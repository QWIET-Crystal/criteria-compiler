# 闭环第一次两轮实测（2026-11-18）

> 目的：验证 `start.mjs → 标注 → refine.mjs → 再标注 → refine.mjs` 这条环，
> 到底会不会让「一致率」真的升。
>
> 结论：**它没升。而且我们发现自己用来衡量它的那个数，本身就是假的。**

## 怎么跑的

| 项 | 值 |
|---|---|
| 问题 | COF 光催化里真正同时发生的水氧化与双氧水生成 |
| 起草输入 | 正例 3 篇、反例 1 篇 |
| 第一轮队列 | 29 篇（cap 400） |
| 第二轮队列 | 8 篇（按新判据重新拉） |

标注口径（本次全程一致）：**同一光催化体系里 H₂O₂ 生成与另一反应真正同时进行**；牺牲剂体系、分开做两次、电催化都不算。

## 结果

| 轮 | 已标 | 正例 | 抓到 | 太窄 | 太宽 | 阈值 | 召回 | 下一轮 |
|---|---|---|---|---|---|---|---|---|
| 1 | 29 | 1 | 25 | 0 | 1 | ≥6 | 100% | 8 |
| 2 | 8 | 0 | 8 | 0 | 0 | ≥8 | — | 0 |

表面上看第一轮「25/26 一致」，很好。**那是假的。**

## 三个发现

### 1. 一致率会被类别不平衡骗

34 篇里只有 **1 篇正例**。把所有论文都判成「不算」，也能拿到 **33/34 = 96%**。

第一版脚本报出来的「96%」，正是这个退化解。已改：现在同时报**抓到几篇「算」**和**误判几篇**，正例少于 3 篇时打警告并明说这个数不可信。

> 这条比任何功能都重要——用一个会被作弊的指标衡量自己，等于没有指标。

### 2. 阈值校准会过拟合

第一轮用 26 篇标好的数据调阈值，`≥1` → `≥6`，训练集一致率 31% → 96%。

第二轮拿 8 篇新论文检验：**0/8 全判错**（8 篇都被判成「算」，实际都不算）。

> 26 篇调出来的阈值，在 8 篇新样本上完全失效。这就是过拟合。所以脚本现在把
> 「上一版判据在新标注上的表现」和「本轮校准后在同一批上的表现」分开报，
> 前者才是检验，后者只是拟合。

### 3. 根因是词表里的领域通用词，不是阈值

当前 14 个区分词里，排在最前面的是：

| 词 | 背景池占比 |
|---|---|
| `charge` | 14.8% |
| `electron` | 13.6% |

它们出现在全部 3 篇正例里，所以按「出现次数」排序时排第一——但它们在这个领域里到处都是。

实测同一批 34 篇的命中数：

```
算     6 个词命中   ← 唯一的一篇正例
不算   7 个词命中   ← 一篇无关的人工光合综述，比正例还高
不算   5 / 5 / 5
```

**正例根本没有被分开，无论阈值取几。** 不是「线画歪了」，是「这些特征不携带这个信息」。

## 结论

术语计数这条路，在这批样本上**根本分不开**。加词、调阈值、补排除项，都只是在拟合噪音。

## 下一步（按优先级）

1. **判据要能表达共现与缺失**，不能只数命中了几个词：
   - 共现：「同一句里同时出现 A 和 B」
   - 缺失：「必须有 X」——第一轮 18 篇「太宽」全是缺这个
2. **领域通用词在进判据前必须硬性剔除**（背景频率 ≤5%），且**不按出现次数排序**——出现次数越多越可能是通用词，排序方向本身就是反的。
3. **正例累积到 ≥10 篇**再谈召回；1 篇正例什么都说明不了。

## 顺带修掉的两个 bug

- `refine.mjs` 原来只读 `draft.json` / `review-queue.csv`，第二轮就原地打转。现在自动取版本号最大的那份。
- 原来只在旧队列里重排，标完就没活了。现在每轮按新判据**重新拉一批**，并把旧队列里没标的带过来。

# 续：换成「共现判据」之后（同日）

按上面的第 1 条，加了 `bench/lib/criteria.mjs`：判据从「数命中几个词」升级成四种可复核的形式
（`any` / `all` / `co-occur` / `absent`），每条都返回**命中的原文片段**。

## 长出来的共现判据

用稀有词（背景频率 ≤5%）配对，正例里同句出现、反例里从没同句出现过：

```
co-1  asymmetric + photosynthesis
co-2  aerobic oxidation + photosynthesis
co-3  aerobic + asymmetric
```

这些是对的——它们确实是这个子领域的签名。

## 但它仍然分不开

队列里排最前的 30 篇，10 篇判下来全是「不算」，其中 **5 篇被判成「算」**。

原因：`photosynthesis` 这个词在无关论文里也会和 `aerobic` 同句出现（「人工光合作用」的套话）。
词级共现能排除一批噪音，但**排除不掉语义**。

## 结论

**人给概念，机器做记账。**

自动起草的价值不在「猜对判据」，而在**把改动做便宜**：
草案里的 `criteria` 是人可以直编的（`refine.mjs` 已经优先读它），
改完立刻能看出它在这一批上匹配到什么程度。

所以学生版的核心动作是**改草案**，不是「标 50 篇」。
标签只能微调；概念只能由人来给。

# 续二：欠拟合检查 —— 判据只认出 2/7

用 `bench/ledger.mjs --criteria <draft.json>` 把学生版草案（3 条判据：`core-any` + 一条共现 + `exclusion`）
在 7 篇已知阳性上跑了一遍。

**认出 2/7。**

那 5 篇没有一篇在同一句里同时出现 `asymmetric` 和 `photosynthesis`——共现判据把精度收窄了，
代价是召回从专家包的 7/7 掉到 2/7。

## 为什么这一趟必须跑

上一轮我看到的「队列变好了」是**假的好**：队列只显示判据抓到的东西，不显示它漏掉的东西。
三篇「不对称光催化产 H₂O₂」看起来漂亮，但另外五篇已知该算的论文，判据连提都没提。

**欠拟合错得很安静**——它不像过拟合那样在训练集上显形，只会让覆盖面悄悄缩小。

## 结论

1. **「队列看起来对」不是证据。** 每次改判据都要跑一次判据账，否则只看到抓到的，看不到漏的。
2. **学生版草案是起点，不是专家包的替代品。** 一个 3 条的草案对着 14 条规则 + 多轴召回 + 三条修正，本来就不该打平。
3. 这条也解释了为什么专家包要留着：它是**召回基线**。学生版跑出来的任何判据，都该先过一遍这个基线，确认没把已知的丢掉。

# 续三：更正上一条 —— 不是 2/7，是「2 强 + 3 疑似」

上一节写「判据只认出 2/7，欠拟合」。**这个结论有一半是错的**，错在我的判定规则，不在判据。

## 错在哪

我原来把判定压成二值：有共现判据时，共现不中就是「不算」。
于是那些**只有泛词命中、没有共现证据**的论文，被记成了「判据认不出」。

加上 `try.mjs --explain`（按命中组合分组）之后，一眼就看见了：

```
A. 3 篇  ← 只命中 core-any          ← 其中 3 篇全是已知阳性
B. 2 篇  ← 命中全部 6 条共现 + core-any
```

A 组那 3 篇被判「不算」，但它们确实是该算的。**判据是够得着的，是我的规则把它判死了。**

## 改成三档之后

| | 数量 |
|---|---|
| 认出（共现有证据） | **2** |
| 疑似（只有泛词，无共现） | **3** |
| 真漏 | 1 |
| 取不到文本 | 1 |

> 够到了（5/6），但多数是弱信号：只有 2 篇有共现证据。
> 说明泛词把范围兜住了，真正的判据还太少。**加共现比加词管用。**

## 为什么必须有三档

真实检索记录第 33–34 行，学生原话：

> 这篇是 nature 上的，我看着属于那种**半是半不是**的，不好确定
> 牺牲剂和高价值产物它们没有明确分开，所以我拿不定主意

**「半是半不是」是真实存在的状态。** 二值判定会替人做一个它没资格做的决定：
要么把它算进来（假阳性），要么把它踢出去（假阴性），两个都不对。

三档的意义是：把「我确定」和「我拿不准」分开交还给人。
这也回到了那条主线——**人合环**。工具不该假装自己知道。

   输出看起来像结论（判据说 0 篇算），其实是没数据。现在直接报错退出。
2. **加了 `--works <csv>` 离线题录**。额度用完也能跑，而且结果和当天网速无关，可复现。
