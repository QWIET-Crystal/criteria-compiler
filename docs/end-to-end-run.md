# 全链路跑一遍（2026-11-18）

> 第一次把六个脚本在同一件事上从头跑到尾。目的不是验证功能，是**拿到每一步的真实数字**，
> 看这条链哪一半健康、哪一半是断的。
>
> 题目：COF 光催化里真正同时发生的水氧化与双氧水生成。
> 输入：正例 3 篇、反例 1 篇（学生版起点），金集 9 篇（7 阳 2 阴）。

## 每一步的数字

| # | 命令 | 结果 |
|---|---|---|
| 1 | `node bench/selfcheck.mjs` | **9/9** 条通过 |
| 2 | `node bench/run.mjs` | A 924 篇 → **2/7**；B 2882 → **5/7**；C 2896 → **7/7**；阴性 0/2 |
| 3 | `node bench/ledger.mjs --pack cof-h2o2` | 查询能召回 **6/7**，剩 1 篇只有 DOI 兜底能拿到 |
| 4 | `node bench/start.mjs ...` | 14 个区分词、**8 条判据**（1 any + 6 co-occur + 1 absent），待标 25 篇 |
| 5 | `node bench/ledger.mjs --criteria ...` | 判据认出 **2/7** ❌ |
| 6 | `node bench/try.mjs --pack` | 25 篇里判据说算 **5** 篇、说不算 20 篇 |
| 7 | `node bench/refine.mjs --pack`（无标注） | 按判据重拉，下一轮 **12 篇** |

## 一句话结论

**这条链的两半健康度差得很远：检索侧 6/7，判据侧 2/7。**

第 3 步和第 5 步量的是两件不同的事，别混：

- **检索侧**（`ledger --pack`）：这篇论文进没进候选池。
- **判据侧**（`ledger --criteria`）：进了池子之后，判据认不认得出它。

前者已经接近满（6/7，第 7 篇靠兜底），后者只有 2/7。

## 三个发现

### 1. 「7/7」和「6/7」不是矛盾，是口径

`run.mjs` 报 7/7，因为它最后开了一步 DOI 兜底直查——拿答案去反查。
`ledger` 报 6/7，因为它只重放**查询**，不含兜底。

两个数都对，但**兜底不算检索能力**。这个区别在报告里必须写出来，否则就成了自我美化。

### 2. 判据侧的短板是结构性的，不是参数没调好

学生版草案有 8 条判据，看上去比专家包的 14 条规则少得不多，但它的构造是“从 3 篇正例里长出来的词”。
那 3 篇没提的说法，它永远抓不到。

金集里漏掉的 5 篇，人工备注本身就说明了原因：

- `self-floating tri-phase; suppresses H2O2 self-decomposition` —— 换了一套描述
- `formulas are space-rendered` —— 化学式被空格拆开
- `H2O2 acts as the oxidant` —— 双氧水是反应物不是产物
- `abstract never mentions H2O2` —— 摘要根本不提

**这四类问题，每一类都不是“再加个词”能解决的。**

### 3. 第 6、7 步之间有个顺序陷阱

先做 `refine`（重拉队列）再做 `ledger --criteria`（查召回），会看到一份很漂亮的队列，
然后以为判据没问题。

**正确顺序是先查召回，再重拉。** 队列只显示判据抓到的，不显示漏掉的。

## 这条链现在的样子

```
selfcheck        设计树和代码有没有分叉
run              三档召回基准（专家包）
ledger --pack    漏检账：哪篇漏了、被哪条查询救回、还是只能兜底
start            起草判据（学生版入口）
ledger --criteria 判据账：认不认得出已知该算的    ← 欠拟合防线
try              改判据，看抓到什么、凭什么
refine           重拉一批 / 按标注学习
```

## 没走到的一步

**标注。** 这是唯一需要人来做的一步，也是唯一一步我替不了。

这次跑没有标注，所以第 7 步走的是“只重拉”分支。带标注的分支在 2026-11-18 上午跑过两轮，
结论是负的（见 `loop-calibration-finding.md`）：一致率没升，而且用来衡量的指标本身被类别不平衡骗了。

## 下一步

判据侧要追上检索侧，缺的不是更多脚本，是**换一种判据写法**：

- 现在：从正例里提取词/词对，命中即算
- 需要：能表达「必须有 X」「A 和 B 不能同时出现」「这条规则只在某类材料上适用」这种结构

在那之前，**学生版草案应当被当作起点，而不是专家包的替代品**——它现在的召回只有专家的 2/7。
